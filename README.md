# Проект: Галерея сотрудников (Django)

Веб-приложение на Django для управления карточками сотрудников и их фотографиями.

## Описание проекта

Проект позволяет просматривать список сотрудников, знакомиться с их навыками и просматривать подробную информацию. 
В приложении реализована система авторизации: страница с детальной информацией о сотруднике доступна только зарегистрированным пользователям.

**Основные возможности:**
*   Главная страница с описанием проекта и карточками сотрудников.
*   Отдельная страница со списком всех сотрудников.
*   Подробная карточка сотрудника (ФИО, пол, навыки).
*   Необязательная галерея изображений для каждого сотрудника с возможностью сортировки фотографий по порядковому номеру.
*   Автоматическое удаление файлов изображений с диска при удалении записи из базы данных.
*   Управление сотрудниками и их фотографиями через стандартную панель администратора Django.

## 🛠️ Технологии
*   Python 3.x
*   Django (Class-Based Views)
*   Pillow (для работы с изображениями)
*   SQLite (база данных по умолчанию)

## 💻 Как запустить проект локально

1. **Клонируйте репозиторий:**
   git clone https://github.com/fedlow/django_staff_project
   cd django_staff_project
Создайте и активируйте виртуальное окружение:

python -m venv venv

# Windows:
venv\Scripts\activate

# macOS/Linux:
source venv/bin/activate

Установите зависимости:
pip install -r requirements.txt

Примените миграции:
python manage.py migrate

Создайте суперпользователя (для доступа в админку):
python manage.py createsuperuser

Запустите сервер разработки:
python manage.py runserver

Перейдите в браузере по адресу: http://127.0.0.1:8000/

📸 Проверка работы
Добавьте сотрудников и их фотографии через панель администратора: http://127.0.0.1:8000/admin/

Страница деталей сотрудника (например, /employees/1/) потребует входа в систему.
